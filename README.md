ELECTRICITY COST PREDICTION SYSTEM USING MACHINE LEARNING 

Overview:
The Electricity Prediction System using Machine Learning based project that predicts electricity costs based on key influencing factors like :
    - Utilization Rate
    - Air Quality Index (AQI)
    - Resident Count 
The system uses a Linear Regression model to analyse user inputs and provide instant electricity cost predictions through an interactive Streamlit interface.

Features
    - Predicts electricity costs accurately using Machine Learning
    - User-friendly Streamlit web interface
    - Real-time predictions based on user inputs
    - Data preprocessing and cleaning
    - Regression-based prediction model

Technologies Used
    - Python
    - Streamlit
    - Pandas
    - NumPy
    - Scikit-learn
    - Linear Regression
